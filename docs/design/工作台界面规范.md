# 评测工作台 · 当前界面规范

本文件记录正式工作台已确认的视觉与交互规则。源码位于 `frontend/`；过时的独立 HTML 原型、A/B 候选稿和重复截图已清理，历史可在 Git 提交中追溯。

## 已确认方向

- 2026-10-28 用户选择 A「对话优先」，采用大标题、明确上传入口和两条起步建议的新对话初始页。
- 左侧历史对话列表完全保持原样：不采用候选稿中的历史项、分组、任务命名或对话改名按钮。
- 保留蓝色、中文系统字体、品牌标识、三栏工作台与大弹窗预览。
- 桌面为本轮优化范围，不新增手机端设计。

## 工作区职责

- 左侧切换历史对话；聊天推动讨论、确认与修改；右侧按产品浏览只读文件。
- 同一对话可有多个产品。展开文件夹和预览文件不改变智能体本轮授权的产品目标。
- 新对话的建议只填入当前对话草稿，由用户主动发送。上传入口共用正式附件接口，支持多份 Markdown / Word `.docx`，上传期间禁用入口。
- 快照同步保留欢迎控件焦点，避免重复进入动画。

## 真实状态与文件

- 完整评测包先展示可编辑大纲，用户确认后生成；已确认大纲保留为只读卡片。
- 生成中按服务端交付项显示完成数和待办；已发布文件可立即预览。输入与上传暂停，终止入口可用。
- 耗时来自本轮开始与结束时间，完成后定格，刷新和重连后恢复。
- 终止后保留已发布文件，标记未完成；可通过聊天续做。以服务端终态恢复输入，同步失败显示重试入口。
- 顶部仅在运行、等待确认、终止或失败时显示状态；正常回复完成和空闲时隐藏状态标签，避免把轮次结束误解为整套方案完成（2026-10-29 用户反馈）。
- 文件区外层按产品归档，内部按“文档 / 数据表”分组。文件名 13px，可换行；逐份显示真实内容版本。
- 完成回复保留智能体真实正文。自动交付卡片只统计本消息关联文件，清单默认折叠，同步期间保留展开状态，刷新后折叠。
- 不固定展示 RAG 摘要，不增加无数据来源的文件用途、语义分类或整包统一版本。
- 文件批量改名保持文件 ID、正文和内容版本不变；旧名链接通过别名打开当前文件。

## 输入与上下文

- 输入区明确显示“上传文档”，保留 Enter 发送与 Shift + Enter 换行。
- 上下文圆环使用近似统计，未知显示“—”；悬停、点击或聚焦可查看口径，Escape 或失焦关闭。
- 真正整理上下文时显示进展，停止按钮仍可用；失败提供可见提示，不展示内部摘要。

## 大弹窗预览

- 聊天清单、生成进度和文件区统一打开当前页面的大弹窗；聊天入口不额外展开右侧文件区。
- 文件名、版本、关闭、下载固定；正文独立滚动。Markdown 与 DOCX 源按 Markdown 渲染，CSV 用只读表格。
- 支持关闭按钮、Escape、遮罩关闭和键盘焦点循环；关闭后恢复入口焦点及聊天阅读位置。
- 加载失败可重试；关闭或切换文件后，旧请求不覆盖新预览。不新增编辑入口。

## 动效与实现

欢迎内容短暂淡入并位移 6px，文件区沿用进入动画，工作区按钮按下缩放到 98%。尊重减少动态效果偏好，不延迟接口动作。样板及取值以 `frontend/index.html`、`frontend/app.js`、`frontend/styles.css` 为准，没有其他待迁移页面。

桌面验收、独立静态视觉评审与保留证据见 [桌面 UI 验收](../桌面UI验收-20261028/验收说明.md)。历史专项说明仍在 `docs/`，正式行为以本规范及当前代码为准。
