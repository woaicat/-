# 需求简介
- 本项目定位为**单用户本地运行**的评测方案设计智能体，所有任务数据、上传文件和生成文件均存储在本机。
- 用户在前端上传需求文档 + 输入产品名称，提交后即可创建任务，后端FastAPI负责接收并触发Agent流程。
- Agent按“规划 → 执行 → 反思”循环推进评测方案设计，过程中会调用文件/目录/向量检索等工具生成产物（md、docx、csv、脚本等）。
- 为简化部署，**暂不接入数据库**，由JSON文件与本地目录承担数据存储；同时保留向量库能力，使用Chroma(DuckDB+Parquet)驻留在本地持久化目录。
- 前端需实时展示任务列表、进度、步骤状态与实时执行事件流，并提供生成文件的预览/下载入口。
- 对接langsmith实现智能体的进度追踪和调试

## 本地单用户精简版架构建议
- **运行形态**：仅部署一个 FastAPI 应用和一个 LangGraph/LangChain Agent 进程，所有数据落在本地目录（JSON/SQLite + Chroma duckdb+parquet），不再引入额外的 PostgreSQL/MongoDB、对象存储或云端依赖。
- **任务调度**：通过 FastAPI 的 `BackgroundTasks`/`asyncio.create_task` 提交后台协程即可满足单任务串行需求，暂不接入 Celery + Redis；如需并发可在后期替换为队列。
- **Agent 最小闭环**：保留 Planner → Executor → Reflector 结构，但先实现“单轮规划 + 线性执行 + 结果写盘”的最小闭环，支持基本的上下文与重试，再根据实际使用情况逐步增加自反思、动态调整等高级功能。
- **工具系统**：优先实现文件写入、目录管理、向量搜索 3 个刚需工具，工具注册表驻留内存即可；随后再按业务扩展 CSV/脚本/接口调用等工具。
- **前端与实时展示**：首期只做一个 Vite + React 单页 + WebSocket 文本流，实时渲染任务列表/进度/事件；文件预览可先提供下载入口，后续再接入 `react-pdf-viewer`、`docx-preview` 等组件。
- **监控与调试**：本地运行阶段通过日志和事件流观测即可，LangSmith 接入留作可选项，在需要远程排障或上云部署时再开启。

## 本地精简版技术栈优先级
- **后端**：FastAPI + LangGraph/LangChain，直接使用 `sqlite` 或 `TinyDB/JSON` 存储任务、步骤、事件；嵌入生成可指向 OpenAI/Ollama，本地模型通过 Ollama/LM Studio 调度。
- **向量与文件存储**：Chroma（DuckDB+Parquet 持久化到 `./storage/chroma`）即可满足检索需求，文件统一落在 `storage/uploads`、`storage/outputs`。
- **任务调度**：默认依赖 FastAPI 自带的后台任务/asyncio，暂不引入 Celery + Redis；当需要扩展到多任务并发/远程执行时再接入消息队列。
- **前端**：Vite + React + TypeScript，UI 组件挑选 Ant Design 即可；WebSocket 仅负责推送进度文本和事件 JSON，文件预览先提供下载链接，必要时再补充 `react-pdf-viewer`、`docx-preview`。
- **监控与观测**：本地日志 + 浏览器事件流即可，LangSmith/OpenTelemetry 接入作为可选项，不影响离线部署。

## 2. LangGraph 化状态机
- 使用 LangGraph 定义 `StateGraph`，将 Planner / Executor / Reflector / Summarizer 拆分为节点，通过 `add_edge`、`add_conditional_edges` 构建 `start → plan → step_loop → reflect → summarize → finish` 的显式流程。
- 在 Graph 中定义统一的 `State`（包含任务元数据、计划、当前步骤、上下文、产物等），各节点通过 `state.update` 使用同一套读写方式，避免逻辑散落在 service 层。

## 3. Checkpointer 与持久化
- 引入 LangGraph 官方的 `SqliteSaver` 或自定义 JSON Saver，将每次节点执行后的状态快照写入本地（建议 `./storage/checkpoints`）。
- 借助 Checkpointer 支持断点续跑、事件回放，并让任务历史查询可以直接读取快照，而非重新执行。

## 4. 事件与可观测性
- 使用 LangGraph 的 `RunnableConfig`/`callbacks` 在节点前后推送事件，替换现有手写广播，与 SSE/WebSocket 保持一致结构。
- 同步接入 LangSmith（可选），通过 `langsmith.run_tree` 获得可视化 Trace；离线模式下保留本地日志，便于回溯。

## 5. 工具注册与上下文管理
- 将 `ToolRegistry` 封装成 LangGraph 的 `ToolNode` 或 `ToolExecutor`，Executor 节点只负责输出工具调用意图，实际执行由 Graph 统一调度。
- 将向量检索、文件写入等上下文数据写入 `State`，由 ContextManager 准备数据源而非直接控制流程，保证节点间的共享上下文一致。

## 6. 前端与事件对齐
- LangGraph 节点的事件 payload 统一包含 `timestamp/step/step_id/status/metadata`，映射至 mock 时间轴所需字段（计划、思考、反思、产物等）。
- SSE/WebSocket 仅关心这些事件，不再依赖内部实现细节，降低前后端耦合度并提升可维护性。

## 7. 迭代顺序建议
1. 完成“梳理现有流程”的文档化，确认状态节点与共享数据。
2. 在现有代码中搭建 LangGraph Demo（Planner→Executor→Summary）验证 `StateGraph` 与 Checkpointer。
3. 逐步迁移全部执行逻辑，最终替换手工 orchestrator。
4. 基于新的事件流更新前端解析逻辑，并对照 mock 时间轴 UI 验证效果。

class EvaluationAgent:

        执行完整的Agent流程
        """
        task = await self.task_service.get_task(task_id)
        
        try:
            # 1. 规划阶段
            await self.task_service.update_task_status(task_id, TaskStatus.PLANNING)
            plan = await self.planner.create_plan(
                task_id=task_id,
                product_name=task.product_name,
                requirements_doc=task.requirements_doc
            )
            
            # 2. 执行循环
            await self.task_service.update_task_status(task_id, TaskStatus.EXECUTING)
            
            total_steps = len(plan.steps)
            completed_steps = 0
            
            for step_index, step in enumerate(plan.steps):
                # 更新进度
                progress = (completed_steps / total_steps) * 100
                await self.task_service.update_progress(task_id, progress)
                
                # 记录步骤开始事件
                await self.task_service.create_event(
                    task_id=task_id,
                    step_id=step.id,
                    event_type="step_started",
                    event_data={
                        "step_order": step.step_order,
                        "description": step.description,
                        "goal": step.goal
                    }
                )
                
                # 获取上下文
                context = await self.context_manager.get_context(
                    task_id=task_id,
                    step=step,
                    plan=plan
                )
                
                # 执行步骤
                step.status = StepStatus.EXECUTING
                await self.task_service.update_step(step)
                
                execution_result = await self.executor.execute_step(
                    task_id=task_id,
                    step=step,
                    context=context
                )
                
                # 反思阶段
                reflection = await self.reflector.reflect(
                    task_id=task_id,
                    step=step,
                    execution_result=execution_result,
                    context=context
                )
                
                # 更新步骤状态
                if reflection.get("is_complete", False):
                    step.status = StepStatus.COMPLETED
                    step.completed_at = datetime.now()
                    completed_steps += 1
                else:
                    # 如果未完成，可能需要调整计划或重试
                    if reflection.get("should_retry", False):
                        # 重试逻辑
                        step.status = StepStatus.PENDING
                    else:
                        step.status = StepStatus.FAILED
                
                step.execution_result = execution_result
                step.reflection = reflection
                await self.task_service.update_step(step)
                
                # 记录步骤完成事件
                await self.task_service.create_event(
                    task_id=task_id,
                    step_id=step.id,
                    event_type="step_completed",
                    event_data={
                        "status": step.status,
                        "reflection": reflection
                    }
                )
            
            # 3. 生成总结
            summary = await self.generate_summary(task_id, plan)
            await self.task_service.update_task_summary(task_id, summary)
            await self.task_service.update_task_status(task_id, TaskStatus.COMPLETED)
            await self.task_service.update_progress(task_id, 100.0)
            
            return {
                "status": "success",
                "task_id": task_id,
                "summary": summary
            }
            
        except Exception as e:
            await self.task_service.update_task_status(task_id, TaskStatus.FAILED)
            await self.task_service.create_event(
                task_id=task_id,
                event_type="error",
                event_data={"error": str(e)}
            )
            raise

                        "result": result
                    }
                )

                    "tool": tool_name,
                    "error": f"工具 {tool_name} 不存在"
                })
        
        return {
            "tool_calls": tool_results,
            "summary": execution_plan.get("summary", ""),
            "raw_response": response.content
        }

from abc import ABC, abstractmethod
from typing import Dict, List
import inspect

class Tool(ABC):
    """工具基类"""
    
    @property
    @abstractmethod
    def name(self) -> str:
        """工具名称"""
        pass
    
    @property
    @abstractmethod
    def description(self) -> str:
        """工具描述"""
        pass
    
    @abstractmethod
    async def execute(self, params: Dict, context: Dict) -> Dict:
        """执行工具"""
        pass
    
    def get_schema(self) -> Dict:
        """获取工具参数schema"""
        sig = inspect.signature(self.execute)
        params = {}
        for param_name, param in sig.parameters.items():
            if param_name not in ['self', 'context']:
                params[param_name] = {
                    "type": str(param.annotation) if param.annotation != inspect.Parameter.empty else "string",
                    "required": param.default == inspect.Parameter.empty
                }
        return params

class ToolRegistry:
    """工具注册器"""
    
    def __init__(self):
        self._tools: Dict[str, Tool] = {}
    
    def register(self, tool: Tool):
        """注册工具"""
        self._tools[tool.name] = tool
    
    def get_tool(self, name: str) -> Tool:
        """获取工具"""
        return self._tools.get(name)
    
    def get_tools(self) -> List[Tool]:
        """获取所有工具"""
        return list(self._tools.values())

    def name(self) -> str:
        return "create_file"

    def description(self) -> str:

    async def execute(self, params: Dict, context: Dict) -> Dict:
        file_path = params["path"]
        content = params.get("content", "")
        file_type = params.get("type", "md")
        task_id = context["task"]["id"]
        
        # 确保目录存在
        Path(file_path).parent.mkdir(parents=True, exist_ok=True)
        
        # 根据文件类型创建文件
        if file_type == "md":
            with open(file_path, "w", encoding="utf-8") as f:
                f.write(content)
        
        elif file_type == "docx":
            doc = Document()
            # 添加标题
            if params.get("title"):
                doc.add_heading(params["title"], 0)
            # 添加内容
            for line in content.split("\n"):
                if line.strip():
                    doc.add_paragraph(line)
            doc.save(file_path)
        
        elif file_type == "csv":
            # content应该是JSON格式的列表
            data = json.loads(content) if isinstance(content, str) else content
            with open(file_path, "w", encoding="utf-8", newline="") as f:
                if data:
                    writer = csv.DictWriter(f, fieldnames=data[0].keys())
                    writer.writeheader()
                    writer.writerows(data)
        
        elif file_type == "py":
            with open(file_path, "w", encoding="utf-8") as f:
                f.write(content)
        
        else:
            raise ValueError(f"不支持的文件类型: {file_type}")
        
        # 保存文件记录
        file_record = await self.file_service.create_file(
            task_id=task_id,
            file_name=Path(file_path).name,
            file_path=file_path,
            file_type=file_type
        )

from fastapi import WebSocket, WebSocketDisconnect
from app.services.task_service import TaskService
import json

class ConnectionManager:
    def __init__(self):
        self.active_connections: Dict[str, List[WebSocket]] = {}
    
    async def connect(self, websocket: WebSocket, task_id: str):
        await websocket.accept()
        if task_id not in self.active_connections:
            self.active_connections[task_id] = []
        self.active_connections[task_id].append(websocket)
    
    def disconnect(self, websocket: WebSocket, task_id: str):
        if task_id in self.active_connections:
            self.active_connections[task_id].remove(websocket)
    
    async def send_to_task(self, task_id: str, message: dict):
        if task_id in self.active_connections:
            for connection in self.active_connections[task_id]:
                await connection.send_json(message)

manager = ConnectionManager()

@router.websocket("/ws/tasks/{task_id}")
async def websocket_endpoint(websocket: WebSocket, task_id: str):
    await manager.connect(websocket, task_id)
    try:
        while True:
            # 保持连接，等待服务器推送消息
            await websocket.receive_text()
    except WebSocketDisconnect:
        manager.disconnect(websocket, task_id)

import chromadb
from chromadb.config import Settings

class VectorService:
    def __init__(self):
        self.client = chromadb.Client(Settings(
            chroma_db_impl="duckdb+parquet",
            persist_directory="./chroma_db"
        ))
        self.collection = self.client.get_or_create_collection("evaluation_docs")
    
    async def add_document(self, task_id: str, content: str, metadata: dict):
        """添加文档到向量库"""
        embedding = await self.get_embedding(content)
        self.collection.add(
            embeddings=[embedding],
            documents=[content],
            metadatas=[{"task_id": task_id, **metadata}],
            ids=[f"{task_id}_{len(self.collection.get()['ids'])}"]
        )
    
    async def search(self, query: str, task_id: str, top_k: int = 5):
        """搜索相关文档"""
        query_embedding = await self.get_embedding(query)
        results = self.collection.query(
            query_embeddings=[query_embedding],
            n_results=top_k,
            where={"task_id": task_id}
        )
        return results
